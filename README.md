# 面向霍尔果斯公路口岸货运拥堵的离散事件仿真与智能调度

## 一、口岸案例

本项目以**霍尔果斯公路口岸货运通关流程**为背景，依据公开流程资料构建情景化仿真模型，不代表对口岸实际运营数据的完整复现。

选择理由：

- 新疆代表性强，案例辨识度高；
- 跨境货运、车辆排队和查验流程适合离散事件仿真；
- 公开资料较多，便于开展研究；
- 不需要获取涉密的真实运营数据；
- 模型可推广到其他公路口岸。

## 二、研究问题

在货运车辆到达量波动和查验资源有限的情况下，如何配置查验窗口并制定调度规则，以降低车辆等待时间和整体通关时间，同时控制服务资源成本？

具体研究问题：

1. 车辆高峰到达时，哪个环节最容易形成瓶颈？
2. 增加固定窗口和高峰动态开窗，哪种方式更有效？
3. 先到先服务、优先级调度和预约分流，哪种规则综合表现更好？

## 三、参赛方向

- **赛道：**数字建模与智能决策
- **方向：**智能决策方向
- **作品类型：**离散事件仿真与通关调度决策系统

## 四、模型范围

第一版模型包含四个主要环节：

```text
车辆到达 → 证件预审 → 联检查验 → 放行复核
```

设置两类车辆：普通货运车辆、时效优先车辆。

比较四种方案：

| 方案 | 内容 |
|---|---|
| S0 | 固定窗口 + 先到先服务 |
| S1 | 增加查验窗口 |
| S2 | 高峰时段动态开窗 |
| S3 | 优先级调度 + 动态开窗 |

重点指标：平均等待时间、平均通关时间、最大排队长度、车辆超时率、服务窗口利用率和单位通关资源成本。

## 五、项目简介

本项目以霍尔果斯公路口岸货运车辆通关流程为背景，构建包含车辆到达、证件预审、联检查验和放行复核的离散事件仿真模型。针对车流波动和查验资源有限造成的排队拥堵问题，比较固定窗口、增加窗口、高峰动态开窗和优先级调度等方案，分析不同车流情景下的平均等待时间、通关时间、排队长度和资源利用率，形成面向口岸管理的窗口配置与调度决策建议，并开发可交互的仿真推演系统。
